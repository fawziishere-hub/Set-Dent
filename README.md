# Sim Dent Ağız ve Diş Sağlığı Polikliniği

Sim Dent için hazırlanmış React, Tailwind CSS ve Supabase tabanlı klinik web sitesi.

## İçerik

- Zirkonyum (Zirconium Veneers)
- Ortodonti (Orthodontics)
- İmplant Tedavisi (Dental Implants)
- Online randevu talep formu
- Klinik bilgileri: Natoyolu, Mamak / Ankara · +90 506 441 72 33

## Başlatma

```bash
npm install
npm run dev
```
